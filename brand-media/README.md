# Tranquilitas shared brand media

Source: Google Drive `Tranquilitas photos` folder owned by Pearson Legacy Ventures. Images are authentic Bahamas brand photography; never claim they were taken at another destination or prove local operations. Hosting: Cloudflare Pages project `tranquilitas-media`, domain `media.tranquilitasspa.com`. Used by independent country websites via absolute HTTPS paths. The media host is the only shared image dependency. Each HTML image has photo-specific descriptive `alt`, image loading is lazy where below fold, and video requires user interaction. 

Images have original file encodings from Drive; next optimization opportunity is modern WebP/AVIF derivatives for large PNGs.
