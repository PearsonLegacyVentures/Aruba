# Tranquilitas Media Library

Authentic treatment imagery from the user-supplied Tranquilitas photos Google Drive folder.

Shared image CDN for all independent Tranquilitas destination websites. Never label these photographs as proof of local spa staff, clients or appointments in another territory. Use the image-specific alt text from `catalog.json` and context-appropriate captions.

Images are loaded lazily except above-the-fold assets. Video is not autoplayed and uses `preload=none`. Source files remain in Google Drive. Images are published unchanged (no face alterations). Last updated: 2026-11-10.
